## Runtime boundary

The shipped default remains:

```json
{
  "autoGenerate": false,
  "model": null,
  "timeoutMs": 15000
}
```

Normal turns use only the local fallback and do not invoke a title model. `/title` resolves the current session model at request time. `model: "provider/model"` and automatic generation are explicit opt-ins. Failures, timeouts, cancellation, configuration errors and stale session results do not block the main task.

Installing or updating files on disk does not hot-load an already running Pi session. New sessions use the package. The current session must be reloaded or restarted before claiming it uses the installed runtime; no active task was force-stopped during this delivery.
